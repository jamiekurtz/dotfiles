FLOATING:

Temporary Float: Press $mod+Shift+Space to turn a tiled window into a floating one, allowing it to be moved or resized freely with the mouse or keyboard.

Automatic Rules: Use for_window [class="..."] floating enable in your .i3/config to detect apps like nm-connection-editor or calculators, ensuring they never disrupt your main layout.

Layout Management: Place floating windows in a dedicated workspace to keep them out of the way, or set them to always float with specialized for_window commands.

Styling: Use for_window [floating_from="user"] border pixel 5 to create larger borders on floating windows to differentiate them from tiled ones.

Window Types: i3 automatically respects window hints, so many dialogs and popup windows will float by default. 




LOCK SCREEN:
Common i3lock Usage and Customization 
Basic Lock: Run i3lock to display a default white/gray screen.
Colored Lock: Use i3lock -c 000000 to display a black screen.
Image Background: Use i3lock -i /path/to/image.png to set a custom PNG image as the lock screen. 

Setting up a Shortcut in i3
Add this to your ~/.config/i3/config file to bind the lock command to Mod+l: 
bindsym $mod+l exec i3lock -c 000000
